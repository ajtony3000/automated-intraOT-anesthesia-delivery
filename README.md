# automated-intraOT-anesthesia-delivery
A closed-loop, wearable-driven anesthesia infusion pump prototype built at the TinkerHub x HOSPEX hackathon. Integrates real-time sensor fusion (HRV, SpO2, Accelerometer) with the Schnider PK model for Propofol TCI. Features safety veto algorithms to filter motion artifacts, treat nociception, and prevent clinical overdose.
